Lição 1

Os arquivos trabalham em equipe

Um site costuma separar o conteúdo, a aparência e as ações. No projeto da barbearia, cada arquivo tem um papel:

  • index.html organiza o conteúdo da página: títulos, textos, imagens, links e formulário.
  • style.css cuida da aparência: cores, tamanhos, espaços e como o site se adapta à tela.
  • script.js cuida das ações: carrega horários, lê o formulário e envia o pedido.
  • supabase-config.js conecta o site ao projeto Supabase. Não compartilhe esse arquivo sem antes entender o que ele contém.
  • admin.html e admin.js formam a página e as ações da área do barbeiro.
Uma comparação: HTML é a estrutura da loja; CSS é a decoração; JavaScript é o que acontece quando alguém aperta um botão.

Palavras básicas do HTML

  • Tag: marca o começo ou o tipo de um elemento, como <p>.
  • Elemento: a tag junto com o conteúdo. Exemplo: <p>Olá</p>.
  • Atributo: uma informação dentro da tag, como id="agendar".
  • Valor: o conteúdo associado ao atributo; em id="agendar", o valor é agendar.
<p class="sobretitulo">ESCOLHA O SEU</p>

<p> cria um parágrafo. class dá a ele um nome de grupo que o CSS pode usar para aplicar estilo.

Lição 2

Links, IDs e seções

Um link pode abrir outra página ou levar a uma parte da página atual. No menu do site, este link leva ao formulário:

<a href="#agendar">Agendar</a>

O símbolo # indica que o destino é uma seção dentro da mesma página. O destino precisa ter o mesmo ID:

<section id="agendar">
    ...
</section>
Regra para lembrar: o valor depois de # no link precisa combinar com o valor de id no destino. Não escreva o # dentro do valor de id.

id e class não são iguais

  • id identifica um elemento específico. Exemplo: id="agendar".
  • class pode ser compartilhada por vários elementos. Exemplo: vários cartões usam class="card".
  • No CSS, uma classe costuma ser escrita com ponto: .card. Um ID costuma ser escrito com cerquilha: #agendar.

Lição 3

Como entender o formulário

O formulário reúne os dados que a pessoa preenche. No site, ele pede nome, telefone, serviço, data e horário.

<label class="campo">
    <span>Seu nome</span>
    <input id="nome-cliente" type="text" required>
</label>
  • <label> agrupa o rótulo e o campo.
  • <span> mostra o texto “Seu nome”.
  • <input> cria um campo para digitar.
  • type="text" indica que o campo recebe texto.
  • required pede que a pessoa preencha antes de enviar.
  • id="nome-cliente" dá ao campo um nome que o JavaScript pode localizar.

Tipos de campo que aparecem no site

  • type="text": texto, como o nome.
  • type="tel": telefone.
  • type="date": data em um seletor de calendário.
  • <select>: menu de opções, usado para serviço e horário.
Conexão importante: se o HTML tem id="nome-cliente", o JavaScript procura esse mesmo ID. Se os nomes não combinarem, o programa pode não encontrar o campo.

Lição 4

CSS e JavaScript

CSS: aparência

O CSS seleciona elementos e define como eles aparecem. A classe botao, por exemplo, pode controlar a forma e o espaçamento dos botões.

.botao {
    padding: 12px;
    border-radius: 8px;
}

O ponto em .botao significa que o seletor está procurando uma class="botao" no HTML. Os valores dentro das chaves definem estilos.

JavaScript: ações

O JavaScript consegue encontrar um elemento pelo ID e reagir a um evento, como o envio do formulário.

document.querySelector("#nome-cliente")

document representa a página. querySelector procura um elemento. O # indica que está procurando um ID.

No arquivo script.js, o envio do formulário segue esta ideia:

  1. Escuta o evento de envio do formulário.
  2. Impede o recarregamento normal da página.
  3. Lê os campos preenchidos.
  4. Envia um pedido ao Supabase.
  5. Mostra uma mensagem de sucesso ou de erro.

Supabase é o serviço online que guarda os pedidos e permite que a área do barbeiro consulte a agenda.

Ao testar: use um pedido fictício e avise o barbeiro antes de fazer testes que possam aparecer na agenda real.
Lição 4 · Quando algo muda de aparência, procure no CSS. Quando uma ação acontece, procure no JavaScript.
